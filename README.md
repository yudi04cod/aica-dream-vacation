# Aica Dream Vacation — One Emoji, One Dream Vacation

One emoji, and nothing else: 🗻 (U+1F5FB, Mount Fuji).

A dream vacation should be one particular place, not any holiday.
Fuji is a postcard in a single glyph — a snow-capped peak under a
blue sky, the trip everyone pictures when they say "one day, Japan".
It is specific where a beach or a plane is generic, instantly
readable at any size on any screen, and it carries the quiet surprise
of choosing a mountain over the obvious seaside.

## How it works

`main.py` (Python standard library only) writes exactly one emoji —
four UTF-8 bytes, no trailing newline, no extra characters — to
`/output/entry.txt`, then reads the file back and verifies it is
byte-for-byte the chosen emoji.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Two runs produce byte-identical output.
